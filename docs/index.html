How to use Armory Forge

On this page (optional)

  1. Each tab is an armor passive: everything you tick goes onto every armor with that passive. + Armor adds another one.
  2. Tick passives to stack them; open one to change its values (the line under each says what it means in game).
  3. Armor weight makes that passive's armors light, medium or heavy; the Armor weight card does it for one armor.
  4. Download builds a ready-to-install mod with this loadout, or Copy share link / Save .ini to share it.

You don't need this page: the mod has the same editor in game.

In game

  1. Install the mod with Bingus Shared Loader and start the game.
  2. Press F7. The panel opens on the tab of the armor you're wearing; the box at the top shows it, and offers to add its tab if there isn't one.
  3. Tick passives on the left, click a name to change its values on the right. It applies at once and saves when you close the panel.
  4. Presets saves loadouts; F9 swaps between them with the panel closed. Copy code / Paste code share them (this page reads them too).
  5. The Guide tab in the panel has all of this, and Keys changes F7 / F9.

The Passive Swap (Lite) edition on Nexus works the same way, with one passive per armor instead of a stack.
